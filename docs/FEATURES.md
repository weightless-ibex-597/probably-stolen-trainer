# Probably Stolen Trainer — feature reference

Probably Stolen Trainer brings session settings and shop records into one section-based interface. Progression notes provides the third part of the workflow.

| Section | Description |
|---|---|
| Session settings | Session and activity information grouped by the task or context it belongs to. |
| Shop records | A dedicated section for shop records and the configuration details associated with that area. |
| Progression notes | A dedicated section for progression notes and the configuration details associated with that area. |

The project page follows the same section structure.
